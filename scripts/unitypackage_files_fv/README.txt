Nt_MLVCFileView（ファイラー）導入用パッケージ

Unity の Assets フォルダを、サムネイル付きのカード表示で見られるファイラーです。
この .unitypackage には本体は入っていません。取り込むと、最新版をインターネットから取ってきて入れます。

■ 使いかた
  1. この .unitypackage を、Unity のプロジェクトにインポートします（全部選んだまま「Import」）。
  2. 開いたウィンドウが、最新版を GitHub から取ってきて、Packages に導入します（自動です）。
     うまくいかなければ「最新版をダウンロードして導入」を押します。
  3. メニューバーに「nyaohtech」が増えます。
       nyaohtech → MLVCFileView

■ 通信について
  ・nyaohtech.github.io（版の一覧）と github.com（ダウンロード）にだけ接続します。
  ・ダウンロードしたファイルは、一覧にある SHA256 と一致したときだけ入れます。
  ・個人情報は送りません。

■ 更新するとき
  案内ウィンドウ（メニュー「nyaohtech → MLVCFileView 導入」）の「最新版に更新」を押します。
  VCC で管理したい場合は、同じウィンドウから「VCC にリポジトリを追加」し、
  「本体を外す」→ VCC の Manage Project で「＋」の順に進みます。
       https://nyaohtech.github.io/nyaohtech-vpm/index.json
  VCC が管理しているプロジェクトでは、更新は VCC から行います。

■ 案内を消すとき
  案内ウィンドウの「この案内を削除」を押します。導入した本体には影響しません。
