ツール

  • Nt_AvatorPerformanceChecker

    v1.0.1

    アバターの「重さ」を、見ながら作れるチェッカー。

    • Scene ビューに、パフォーマンスランクを常時表示
    • PC / Mobile それぞれの全項目を、色分けして一覧表示
    • テクスチャの VRAM レポートと、アップロード容量の目安
    • 日本語 / English の切り替え
    Unity メニュー: nyaohtech → アバターInfo
    アップロードされない非アクティブ / EditorOnly は集計しません。

  • Nt_SimpleMatResize

    v1.1.1

    テクスチャを一括で小さくして、アバターをぐっと軽く。

    • アバターを複製して縮小するので、元のアバターは変更されません
    • 上限を 1024 / 2048 / 4096 から選べます
    • 縮小したテクスチャとマテリアルを、新しいプレファブにまとめて保存
    • ノーマルマップや sRGB など、元のインポート設定を引き継ぎ
    Unity メニュー: nyaohtech → アバター軽量化
    出力先: Assets/SimpleMatResize/Generated

  • Nt_AvatorSupports

    v1.0.0

    上の 2 つを、まとめて一度に入れられる詰め合わせ。

    • Nt_AvatorPerformanceChecker と Nt_SimpleMatResize を同時に導入
    • VCC で「Nt_AvatorSupports」の「＋」を押すだけ（これ自体に機能はありません）
製品ページを見る（公式サイト）

導入のしかた

  1. 上の「VCC に追加する」を押して、VCC の確認ダイアログでリポジトリを追加します。
  2. VCC でアバタープロジェクトの「Manage Project」を開き、使いたいパッケージの「＋」を押します。
  3. Unity を開くと、メニューバーの nyaohtech から使えます。

よくある質問

対応している Unity は？

VRChat 推奨の Unity 2022.3 以降を想定しています。VRChat のアバタープロジェクトで使ってください。

Nt_SimpleMatResize で元のアバターは壊れませんか？

元のアバターは変更せず、非表示にするだけです。縮小した画像は別のファイルとして書き出すので、元の画像にも触りません。Ctrl+Z でも戻せます。

Nt_AvatorPerformanceChecker の数値は VRChat の表示と同じですか？

ランクの基準は VRChat 公式の値です。VRAM やアップロード容量は目安の概算なので、最終確認は VRChat SDK のビルド画面で行ってください。
